Privacy Policy

Last updated: October 22, 2026

This Privacy Policy describes how the YouTube Channel 14 Uploader application collects, uses, and handles information for the YouTube channel Donna Gonzales.

Contact Information

Google API Scopes Used

YouTube Channel 14 Uploader accesses Google APIs strictly for managing and publishing content to the Donna Gonzales YouTube channel. The application requests access to the following 5 Google OAuth scopes:

  • https://www.googleapis.com/auth/youtube.upload - Used exclusively to upload scheduled video content to the Donna Gonzales YouTube channel.
  • https://www.googleapis.com/auth/youtube - Used to manage channel metadata, video titles, descriptions, tags, and settings.
  • https://www.googleapis.com/auth/youtube.force-ssl - Used for channel management operations and posting replies to viewer comments.
  • https://www.googleapis.com/auth/yt-analytics.readonly - Used to retrieve performance reports, views, watch time, and subscriber metrics.
  • https://www.googleapis.com/auth/drive - Used to read video files and thumbnails stored in the designated Google Drive folder for upload, and to move processed files to an uploaded subfolder.

Data Storage and Protection

OAuth tokens and API credentials are kept securely in private GitHub repository secrets and encrypted local storage. No user data is sold, transferred, or shared with third parties.

Revoking Access

You can revoke access to this application at any time via your Google Account Security Settings.
